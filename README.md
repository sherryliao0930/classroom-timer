# 課堂計時器

投影在黑板上使用的倒數計時器與碼錶。單一 HTML 檔、不需網路、不需安裝，雙擊就能開。

線上版：<https://sherryliao0930.github.io/classroom-timer/>

## 功能

- **倒數計時**：1 / 5 / 10 / 20 / 40 分快捷鍵，按下去只是「設定時間」，要自己按「開始」
- **微調**：－1 分 ／ －10 秒 ／ ＋10 秒 ／ ＋1 分，倒數中也能加時間
- **碼錶**：可分段記錄
- **四段式提醒**
  | 剩餘 | 畫面 | 聲音 |
  |---|---|---|
  | 60 秒 | 數字轉紅 | — |
  | 30 秒 | 整塊閃動（一秒一次） | — |
  | 10 秒 | 閃動加速（半秒一次） | 每秒催促音，最後 3 秒雙響 |
  | 0 | 滿版「時間到」交替閃爍 | 鈴聲循環，按停止為止 |
- **鈴聲三選一**：急促鬧鈴／下課鐘聲／旋律提示，可調音量、可試聽
- 深色主題、全螢幕、防止螢幕休眠

## 鍵盤快捷鍵

| 按鍵 | 功能 |
|---|---|
| 空白鍵 | 開始／暫停（鈴聲響時按可停止） |
| R | 重設 |
| F | 全螢幕 |
| 1〜5 | 選 1／5／10／20／40 分 |
| L | 碼錶分段 |

## 使用說明

上課前先按一次設定裡的「試聽鈴聲」確認音量——瀏覽器規定要先有一次點擊才允許出聲。

時間到之後直接再按「開始」，會重跑一次同樣長度，不必先按重設。

## 技術

- 單檔 HTML，沒有任何外部資源，離線可用
- 鈴聲全部用 Web Audio API 即時合成，沒有音檔
- 計時由 `requestAnimationFrame` 與 `setInterval` 兩路驅動，視窗切到背景也不會停
